# 设置中心展示与交互标准

适用于 Desktop 的全部设置主页面、子页面、内联编辑器及弹窗。新增页面和修改既有页面必须遵守本标准。设置值、权限边界、模型协议及原生宿主能力仍由各自业务契约负责。

## 页面结构

- 主页面使用 `SettingsPageShell`，保留一个可访问的 h1、当前导航状态和明确的保存策略说明。
- 四种模板：表单（最大 960px）、列表（1040px）、工具（1200px）、主从详情（填满可用区域，详情表单限宽 920px）。这些宽度由内容任务决定，不逐页任意指定。
- 页面外边距桌面为 24px / 32px，窄窗口为 16px；分组间距 24px，表单行间距 16px。文字说明允许换行。
- 平铺分组与页面网格对齐；有底色或边框的卡片必须有内边距。模型详情及新增表单桌面 20px、窄窗口 16px；空列表至少 12px。不得以清零卡片 padding 消除多余嵌套。
- 主页面保持一级导航。窄窗口使用可搜索的设置选择器，必须可见、可聚焦且不被详情布局覆盖。
- 子页面使用 `SettingsSubpageHeader`：返回入口 → 标题与工具栏 → 说明与保存策略。返回入口用箭头和文字明确返回父级；不能与“返回工作区”混用。内联编辑器保留父页面上下文，弹窗使用命名标题和关闭按钮。
- 设置区分 h1 页面、h2 子页/分组、h3 卡片/次级分组，不重复相邻的同名大标题。

## 控件与操作栏

- 下拉选择使用 `SettingsSelect`，分段选项使用 `SettingsOptions`；暴露选中、禁用、展开和焦点状态，支持键盘操作。
- 单纯的选择、搜索和筛选不会自动提交所在表单。每个表单只有一个主要提交动作；删除等危险动作单独呈现并保留既有确认机制。
- 工具栏在标题区域，搜索在列表上方；编辑操作栏在编辑内容之后。操作栏统一使用 `settings-save-bar`：左侧状态，右侧取消/次要操作与保存/主要操作；窄窗口换行，不覆盖可编辑内容。
- 无更改时禁用手动保存；提交期间禁止重复提交。失败保留用户输入及可操作的错误；成功只能在服务确认后显示。
- 图标按钮必须有可访问名称；重要状态使用文字，不能只用颜色圆点表达。“已配置”不得暗示连接检测成功。

## 保存策略

| 类型 | 行为 | 页面/子页面 |
| --- | --- | --- |
| 自动保存 | 更改后执行既有持久化，显示确认结果；文本型内联编辑仍保护尚未提交或失败的草稿 | 通用、模型偏好、权限、沙箱、浏览器控制、外观概览、详细排版、快捷键、Skills 开关 |
| 手动保存 | 用户点击保存后持久化，显示未保存/保存中/成功/失败 | 模型连接、网络、Hooks、预设、子智能体档案、MCP 编辑、记忆指令文件 |
| 应用到父级草稿 | 子弹窗只修改父编辑器草稿；父级保存后才持久化 | 模型参数弹窗 |
| 预览后应用 | 浏览和预览不等同于保存；应用或保存后才提交。退出取消预览 | 主题库、主题编辑器 |
| 明确动作 | 必须点击动作按钮；“保存并继续”不得执行安装、发送反馈、连接服务等外部动作 | MCP 新增并连接、插件安装、添加模型服务目录、反馈发送、导入、诊断、缓存清理 |
| 只读 | 无保存按钮，不显示虚构的保存状态 | 用量统计、存储与路径等只读信息 |

“保存成功”和“运行时已生效”是两个状态。模型设置已持久化但运行时待应用/失败时，保留对应提示与重试入口。

## 未保存更改与导航

所有持久化草稿通过 `useSettingsDraft` 注册到当前 `SettingsExperienceProvider`。搜索、筛选、展开状态、选择中的列表行不注册。

1. 侧栏切页、外部设置目标跳转、返回工作区、返回父级、切换连接/工作区/编辑目标，以及关闭或取消编辑器，都先通过 `requestLeave`。
2. 无草稿立即导航。有草稿显示统一确认框：**继续编辑 / 放弃更改并离开 / 保存并继续**。默认焦点在继续编辑，Escape 等同继续编辑。
3. 保存并继续仅对可保存且已通过即时验证的草稿启用；JSON 等完整解析在保存时完成，失败留在原处。依次保存子编辑器和父编辑器，即使父编辑器原本干净、只在子编辑器应用后变脏，也必须持久化父级。任何一步失败都停止导航并保留剩余草稿。保存期间的新编辑不能被先前的成功响应覆盖或丢弃。
4. 放弃会调用草稿拥有者的重置逻辑，再执行目标导航；继续编辑保留所有值。已成功保存的部分不会回滚。
5. 尚未完成的安装/连接/反馈动作只提供继续或放弃，不在导航确认中自动执行。
6. 页面刷新、浏览器/窗口卸载使用 `beforeunload` 保护脏草稿；原生宿主是否允许卸载提示由宿主机制决定。不要用原生 `confirm()` 替代可测试的页内确认。
7. 取消确认恢复触发控件焦点；子页返回恢复父级上下文。设置中心 Escape 不直接退出到工作区。

草稿不得写入日志、截图文本报告、浏览器持久化存储或文档；尤其不得持久化 API 密钥草稿。注册表仅保存当前组件引用，组件卸载时移除。

## 加载、空状态、错误与成功

- 使用 `SettingsFeedback` 的 `loading / empty / error / success / info` 语义和视觉规则。遗留业务容器 `empty / mem-empty / banner / mem-error` 共享相同的间距、文字和边框规则，不能自建与主题脱离的颜色。
- 首次加载显示 `role=status`、加载文字及忙碌状态；请求失败终止加载，显示 `role=alert` 和重试入口。不得把请求失败转换为空列表，也不得无限显示加载。
- 真正为空时说明没有内容；筛选结果为空时说明没有匹配项，保留搜索及清除筛选入口。只读或能力不可用与加载失败分别解释。
- 更新请求保留已有数据；错误放在对应页面或字段附近。验证错误可读、可定位，错误提示不能把失败输入清空。
- 成功使用 `role=status`；有业务结果文字的用具体结果，没有结果文字的用“更改已保存”。禁止初始加载即宣称保存成功。
- 外观/主题等原有 toast 操作通过 `useSettingsNotice` 汇入设置中心反馈；错误需保留可读详情。一般成功反馈约 4 秒自动收起，关键错误持续显示直到后续操作。
- 不支持原生能力时显示具体不可用说明，不显示可操作但无效的控件。

## 页面验收矩阵

主页面必须全部检查，默认结构与保存策略如下：

| 页面 | 模板 | 保存或动作 |
| --- | --- | --- |
| 通用 | 表单 | 自动保存；声音与状态栏内联展开 |
| 模型偏好 | 表单 | 自动保存；自定义比例文本保护尚未提交/失败的草稿 |
| 模型服务 | 主从详情 | 连接详情手动保存；模型参数先应用到父级；目录连接为明确动作 |
| 用量统计 | 工具 | 只读；范围切换、加载失败可重试 |
| MCP 与工具 | 列表 | 开关/重连为明确操作；配置编辑手动保存；新增并连接须明确提交 |
| 机器人渠道 | 列表 | 新配置支持仅保存/保存并连接；已启用配置保存后自动重连；断开取消启用，重启恢复已启用项；草稿保护与删除确认 |
| 智能体预设 | 列表 | 新增/复制/编辑手动保存；内置项只读 |
| 团队 | 列表 | 成员、预设副本及群组手动保存；冲突保留草稿；排序立即保存；删除需原位确认并保留历史；忙碌目标提供停止入口 |
| Agent Skills | 列表 | 开关自动保存；刷新/删除为明确动作 |
| 子智能体 | 列表 | 档案手动保存；试运行为明确动作 |
| 插件 | 列表 | 安装、更新、移除均为明确动作 |
| 记忆 | 列表 | 指令文件手动保存；新增/恢复/删除为明确动作；切工作区保护草稿 |
| Hooks | 工具 | JSON 手动保存；作用域切换保护草稿 |
| 诊断 | 工具 | 读取、复制、探测和修复为明确动作 |
| 权限 | 表单 | 选择自动保存；新增规则保护未提交文本 |
| 沙箱 | 表单 | 选择自动保存；目录文本保护未提交草稿 |
| 网络 | 表单 | 手动保存；缺少必要代理参数时禁用保存 |
| 浏览器控制 | 表单 | 选择自动保存；导入/清理为明确动作；无宿主能力时解释不可用 |
| 外观 | 表单 | 基础选项自动保存；主题库预览后应用；主题编辑器明确保存 |
| 快捷键 | 列表 | 确认组合键后保存；冲突保留原配置并解释 |
| 存储与路径 | 表单 | 路径只读；复制显示结果 |
| 关于 | 工具 | 偏好自动保存；更新与反馈为明确动作 |

子页面至少覆盖：声音和状态栏编辑、模型高级设置、模型服务新增目录/自定义连接/详情/高级设置/参数弹窗、MCP 注册表/新增/详情/编辑、预设新增/复制/编辑、子智能体档案、插件本地/Git 表单、记忆各标签及指令文件编辑、主题库/主题编辑器/详细排版各区域。

每项检查：标题与父级返回、工具栏与操作栏、保存策略文字、初始/加载/空/错误/成功、无更改/有更改/验证失败/保存失败/重试、切页继续/放弃/保存、刷新保护、键盘焦点、长文字/路径、卡片两侧留白及控件可达性。

验证命令在 `desktop/frontend` 执行：

```sh
pnpm build
pnpm test:settings-responsive
pnpm test:settings-browser
pnpm test:settings-pages
pnpm test:typecheck
```

`settings-pages` 对中英文、1600/900/400px 页面和子页面检测溢出、卡片文字贴边及窄窗口导航，并操作网络、Hooks、预设、MCP、连接、插件、记忆文件和主题编辑器的离开保护；`settings-browser` 覆盖主题、平台、缩放与表单/模型选择器交互；`settings-draft-navigation.test.tsx` 验证草稿生命周期、失败保留、并发编辑及子父级保存顺序；`settings-feedback.test.tsx` 验证加载中、失败停止加载和成功重试。测试结果不能代替截图复查，也不能宣称真实服务、原生窗口关闭或安装已验收。

## 维护约束

机器人渠道的保存例外（用户明确要求）：`BotChannelsSettingsPage` 对已启用
机器人保存后恢复其连接；新配置的导航“保存并继续”仍仅保存、不启用。
显式“保存并连接”可以启用新机器人。通过 Bot 生命周期与草稿导航测试验证，
保存成功和连接成功分别反馈。

- 先修改共享组件，再迁移同类页面；不要新增逐页的标题、返回、保存栏或状态反馈实现。
- 布局参数、卡片 inset 和状态视觉应在共享样式中维护。专用图表、预览、目录主从结构允许差异，同行为的页面不允许任意差异。
- 任何例外必须在此文档写明用户原因、拥有组件和验证方法。新增页面必须加入导航与逐页测试矩阵，新增草稿必须加入导航保护回归。
- 修改上述标准时同步更新实现、测试和此文档；禁止只更新报告或放宽几何断言来掩盖回归。
