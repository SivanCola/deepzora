# 团队实现

七层完整栈在输出、持久化、历史、流式及三平台原生遮罩验收后开放团队密钥；单独的
第六层基础设施仍保持关闭。平台与模型覆盖见[验收记录](TEAM_ACCEPTANCE.md)。
值存于独立、不可变的本地未加密凭据槽，不导出到全局环境。POSIX 命令需直接引用
`$DEEPZORA_SECRET_NAME`，Windows PowerShell 需直接引用
`$env:DEEPZORA_SECRET_NAME`；间接引用、非法脚本和不支持的 Shell 不注入值。
密钥命令使用独立进程，不能交给宿主终端或常驻 Shell。

在 **设置 → 团队 → 团队记忆** 中选择团队、群组或成员。成员私有事实跟随其各个席位；
共享记忆工具对每次具体改动都申请新的人类审批。版本冲突会保留草稿，需明确重新载入
已保存的版本后审阅并重试。

**自动整理记忆** 默认关闭，只使用新的人类消息和已有事实，保留固定指导，排除成员
回复及定时输入。可指定整理模型引用，留空使用默认聊天模型。模型不可用时记录失败，
不会自动选择其他连接。整理使用模型额度；关闭时会取消并等待当前调用清理完成。

**团队定时任务** 可以指定成员或群组，支持一次、每天、每周，以及 10 分钟至 7 天间隔。
保存 IANA 时区；开始日期使用带明确 UTC 偏移的 ISO 8601 时间，例如
`2026-11-04T09:00:00+08:00`。每日和每周时间使用保存的时区，设备更换时区不会改变它；
夏令时中不存在的本地时刻会跳过。

定时任务仅在应用打开时执行，错过超过两分钟的工作会跳过；目标忙碌时只在该窗口内
等待。**立即执行** 仍然提交定时来源的输入，不批准敏感工具、不扩大成员权限，也不恢复
已停止的 Goal。派发中断后，先检查目标会话再决定是否创建新的执行 occurrence。
**归档成员** 会停止其执行准入并保留身份、私聊记录和预设副本；仍有执行、审批或未消费
交换时会拒绝归档。可在 **已归档成员 → 恢复成员** 恢复同一成员，之后需审阅并重新添加
群组关系。删除成员不会获得此恢复入口。

[English](TEAM.md)

Team 面向本机 macOS、Linux、Windows Desktop，进度见[交付清单](TEAM_PORT_STATUS.md)。
提供存储、编排、Controller 席位、成员和群组配置、私聊、群聊、共享记忆、自动整理、
定时任务、密钥授权、全边界精确值遮罩及成员用量。每个数据目录只有一份名册，最多
32 名成员、16 个群组；不提供 CLI、Serve、ACP、机器人或 SSH 团队入口。

## 状态归属

`internal/teamroster` 管理带版本的名册、revision 校验、交换账本、群日志和轮次状态。
写入使用 Deepzora 的文件身份锁和严格原子替换。宿主驱动服务前必须取得写入租约；
Store 本身是持久化原语，不是授权边界。

`internal/team` 管理成员授权、有界交办、群发言顺序、计时和恢复，通过 `Panes` 接口
驱动会话。`Pane.Deliver` 只有在 inbox 持久化成功后才可返回成功；Controller 必须通过
`Settlement` 报告真实结束状态和实际消费的回复。

`internal/hostframe` 将不可信文本中的宿主标签转义，不授予执行权限。成员指令和消息
仍需遵守接收方的执行权限。

## 持久化与兼容

名册 schema 1 是新建的 Deepzora 数据，只接受 `read-only`、`workspace-write`、
`danger-full-access` 三种规范权限值；未指定权限由桌面宿主解析。不导入 Reasonix
数据。更高版本拒绝写入；损坏数据保留并报错。JSONL 末尾中断的半行在读取时跳过，
下次追加前清除。

同一请求 ID 只能重试完全相同的发送者、接收者、父交换、群组、回复目标、执行上限
和消息。重启先将未完成交换与轮次结算为中断，Controller 拒绝已结算任务
在 inbox 中重放。

团队数据使用独立版本命名空间，不批量重写既有会话和预设。停用团队定时任务后停止
新调度并保留数据；回退旧应用前需退出所有新版本进程，旧版本不能写入新 Team 数据。
用量索引可由原始记录重建；壳、服务及前端契约摘要不匹配时继续拒绝启动。

租约用于三平台上协作进程的互斥，不能隔离同一系统用户运行的其他程序。Windows
Shell 继续遵守 Deepzora 现有的当前系统账户执行约定。

## 验证

运行 `go test ./internal/teamroster ./internal/team ./internal/hostframe`，支持的平台补充
相同包的 `-race` 检查。覆盖 revision 冲突、损坏与未来版本、真实子进程租约竞争、
规范权限、幂等、交办循环、回复消费、群计时、审批契约及重启恢复。Windows 交叉编译
只证明可编译，原生运行仍是独立验收项。

普通 boot 保持既有模型请求与工具目录。团队 boot 注册一致的团队工具，将当前身份追加
到回合尾部。团队输入带有宿主来源及临时执行上限，不覆盖成员的长期权限；持久配置审批
提交时校验用户审阅的名册 revision。既有会话、预设和凭据格式不变。新增 Desktop 命令
与事件会改变契约摘要，Go、前端和 Electron 必须配套使用。
提取代码的 MIT 许可证保留在 `internal/team/UPSTREAM_LICENSE`，同时覆盖名册与宿主
framing 包。

## 桌面生命周期

`desktop/internal/teamhost` 管理单一写入租约和同席位的串行创建。桌面适配复用现有
会话服务、工作区注册表、Controller 和后台运行时注册表，保存规范会话身份；后台交办
不切换当前工作区。关闭团队聊天只释放显示引用。后台空闲十分钟可回收；超过六个席位
时只回收可安全关闭的空闲席位，待审批、inbox 和后台任务仍保留运行时。

退出先停止时钟和新准入，关闭席位并等待 Controller 实际释放存储后，再释放团队租约。
配置命令校验 revision，并把有界重试回执与配置原子提交；冲突保留调用方草稿，复用
请求键修改内容会被拒绝。工作目录继续走普通程序审批，名册路径不自动授予信任。
预设保存完整副本，包括完整提示词模式、运行时上下文选项，以及无限制和空工具白名单
的区别，源预设后续修改不会改变成员。

Go 通过私有浏览器授权传递成员身份，Electron 据此生成持久分区。同成员的不同席位
共享登录，不同成员隔离。用户打开页面也由 Go 解析所属成员，页面不能指定分区。
恢复页面沿用分区，并拒绝被替换页面实例的迟到回调。

## 桌面团队导航

从侧栏“团队 → 管理团队”创建成员和群组。成员保存预设的完整配置副本，包含提示词
模式、运行时上下文及工具限制，可在成员编辑器继续修改，源预设后续变化不会影响它。
初始模型只用于新会话。名称和头像立即更新；静态提示词及工具变更在空闲边界重建，
期间显示“已保存，将在空闲后生效”。

私聊在输入框上方显示成员名称和头像，标题标明成员及“私聊”。通过“成员设置”修改
成员独立配置；聊天页权限选择器可直接保存成员权限，同步到该成员所有私聊和群聊。
完全访问需要确认，并发配置冲突要求重新核对，不自动重试。模型选择仍可切换当前会话模型。内部成员
工作目录不会作为普通项目重复出现。

成员权限统一控制私聊及群聊席位，恢复和普通会话权限接口不能绕过该持久配置。Full access
复用现有桌面确认，保留 Windows Shell 的真实权限说明。工作目录变更要求相关席位
空闲，并在可验证的已完成回合边界创建新规范会话，保留对话。修改后从团队导航重新
打开成员；旧绑定拒绝新工作。目录仍走普通工作区信任检查。

成员和群组支持排序、置顶和隐藏，隐藏不停止执行。删除需原位确认，有执行、审批、
未消费交换或群接力队列时拒绝，并提供停止相关目标的入口。删除保留历史身份及日志；
退役群组可在“已归档历史”阅读，不能发送新消息。

群聊复用现有 Transcript、ChatSource 和唯一视口写入者。提及保存成员 ID，支持名称
含空格，成员退出后明确提示失效。历史双向分页，每页 32 条、最多驻留 3 页；追加不
使旧游标失效，替换返回 `stale_cursor`，保留当前阅读窗口直到显式刷新。用户上翻时
延后实时替换。

群输入、提及和提交 ID 在团队命名空间持久保存。草稿独立校验 revision，冲突保留
输入，需明确放弃并重读才能覆盖。退出等待已接收的提交和草稿保存；重启后重试复用
持久提交身份。已读位置绑定已展示的快照，迟到回执不能把替换日志标为已读；私聊未读
复用现有规范会话的可见结果序号。

浏览器验收使用现有预览桥接，不伪造成员模型回复；它与原生宿主、真实模型及安装包
验收分别记录。

## 密钥、脱敏与用量

**团队密钥** 仅在密码输入框中接收明文，查询只返回元数据。授权保存具体
成员 ID，空列表不授权任何人，新成员不会继承授权。替换或删除立即禁止新命令使用，
旧值继续进入可跨重启恢复的退役遮罩集合。**忘记退役遮罩值** 需独立确认，可能让历史
中的旧值重新可见，不能用删除操作代替该确认。
确认后也会删除退役凭据文件；待清理记录持久保存，中断或文件占用后在桌面应用运行
期间重试，并在设置中提示剩余清理状态。当前仍在使用的凭据文件不能成为清理目标。

密钥不进入全局环境及普通凭据 `.env`。即使关闭可选敏感文件规则，文件工具仍拒绝
专用宿主目录；递归搜索与该目录重叠时使用宿主内的逐文件权限检查。POSIX 和
PowerShell 通过 AST 识别直接引用，解析不会执行待检查的脚本。

每次脱敏边界重新读取实际槽内容，同长度、恢复修改时间的替换也会更新遮罩。当前和
退役值覆盖 Provider 消息、工具说明与 schema、扩展帧、进度、错误、日志、后台产物
和新会话输出。流式处理跨块值；JSON 在标量 token 层处理，保留重复键及未命中字节。
宿主的序号及用量计数仍保持数值类型。

原协议适配器仅为自己的协议回放必要签名证明，其余接收方仍使用脱敏副本。持久化
脱敏改写了签名绑定的正文时，消息会带上失效标记，适配器在 HTTP 前拒绝回放。此时
需新建对话，不能继续使用失效证明。工具、文件写入与 MCP 拒绝执行 `[secret:…]`
占位符，避免把遮罩误当真实值。

旧不可变历史在首次读取时投影，保留原始对象；发现敏感内容后生成新内容身份，旧
范围授权返回 `stale_secret_projection`。开启遮罩时，超过 64 MiB 的单个历史正文
会拒绝读取。同系统账户仍可访问原始本地数据及未加密凭据槽；精确值遮罩无法阻止
编码或变换后的泄漏，也不提供操作系统级 Shell 隔离。

**成员用量** 按成员、群组、规范席位、模型及调用来源聚合真实调用记录，涵盖主调用、
任务子 Agent 和自动整理；每个计费事件只记录一次。旧记录保留为“未归属”，保留多
币种、估算及缺少定价原因，原有全局统计及可重建索引不改变。

手动运行 **CI → Run workflow → team_acceptance** 可构建可安装包、检查打包后的
壳与服务、执行团队流程，再从 DMG 复制应用或安装 DEB／NSIS 后重复验证，并检查
原生浏览器 Cookie 隔离。只上传验收产物，不发布。
loopback Provider 是受控模拟，不能作为真实模型验收证据；实际完成状态见交付清单。
